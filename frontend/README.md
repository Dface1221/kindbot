# Expert to Skill - Frontend

The interactive user interface for **Expert to Skill** is integrated directly into the FastAPI backend and served at `/demo`.

To view and use the web interface:
1. Start the backend: `python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir backend`
2. Open `http://127.0.0.1:8000/demo` in your browser.
